# Los Del Sur - Catálogo de Accesorios 🚗

Catálogo online para e-commerce de accesorios automotores. La plataforma permite a los clientes explorar el stock disponible y deriva automáticamente a WhatsApp para la coordinación y cierre del pedido.

## 🌍 Demo en vivo

[Ver catálogo funcionando] https://losdelsuraccesorios.netlify.app/

## 🛠️ Tecnologías utilizadas

- Frontend: HTML, CSS, JavaScript
- Integración con API de WhatsApp para checkout
- Hosting / Deploy: Netlify

## 🚀 Cómo correrlo localmente

Al ser un sitio estático, no requiere configuración compleja:

1. Clonar el repositorio: `git clone https://github.com/nachogomezrp/LosDelSur1.0.git`
2. Abrir el archivo `index.html` (o el principal) en cualquier navegador.
